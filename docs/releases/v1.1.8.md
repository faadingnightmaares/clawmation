Automatic updates now select the correct Windows installer every time.

## Update reliability

- **One supported installer:** Releases now publish the NSIS installer used by
  Clawmation's updater instead of also producing an MSI that could be selected
  by mistake.
- **Correct signed manifest:** The in-app update manifest now points at the
  installer Clawmation can download, verify, and install automatically.
- **No macro changes:** Recording, playback, and automatic legacy-macro repairs
  remain unchanged from v1.1.7.
